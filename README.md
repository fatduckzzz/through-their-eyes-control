# 对照组材料：科普文字版

实验组（`site/`）是沉浸式交互网站；本目录是对照组的**科普文字版**。
两组的**信息内容相同**，只有**呈现形式**不同——这是本实验的自变量。

```
site-control/
├── index.html    # 全部内容，单页长文
├── style.css     # 朴素排版，无动画、无色彩编码
├── tracker.js    # 曝光计时 / 事件记录 / 完成码（两组共用同一份）
└── README.md
```

打开方式：直接双击 `index.html`，或 `python -m http.server` 后访问。无构建步骤、无依赖。

---

## 一、操纵了什么，控制了什么

| | 实验组 `site/` | 对照组 `site-control/` |
|---|---|---|
| **信息内容** | 相同 | 相同 |
| 人称 | 第二人称（"你叫亚历克斯"） | 第三人称说明文 |
| 视角占据 | 有：选择色觉类型、代入一整天 | 无 |
| 色觉模拟 | 有：SVG 滤镜实时改变画面 | 无 |
| 交互 | 有：选择、反馈、开关、配色工具 | 无（仅滚动） |
| 叙事张力 | 有：悬念、反转、日落揭示 | 无 |
| 情绪化视觉 | 有：暗色影院感、动效、氛围 | 无：白底、正文排版 |
| 当事人自述 | 第一人称引语 | 第三人称转述（内容相同） |

**因此可归因的自变量 = 叙事化 / 具身化 / 交互式呈现形式。**
如果实验组共情得分更高，不能被解释成"实验组看到的信息更多"。

## 三、两处需要你确认的取舍

1. **配色工具 `#ctool` 没有放进对照组。**
   之前的方案是"对照组保留所有非叙事模块，包括配色工具"。但那个工具本身就是一个**交互式色觉模拟器**——放进对照组会把自变量从"叙事+具身+交互"稀释成"仅叙事"。
   现在的做法（第十一节把工具的知识点写成文字）对应的是**形式操纵**；如果你想改成**纯叙事操纵**，把 `#ctool` 整段复制过来即可，两种设计都成立，但结论的措辞不同：
   - 现方案结论："交互式具身叙事 > 说明文"
   - 另一方案结论："叙事框架 > 说明文（在交互程度相当时）"

2. **对照组目前只有中文。** 实验组有 EN/中文 切换。腾讯样本服务是中文被试，实际投放没问题；但如果要在论文里声称两组材料完全等价，最好把切换功能一并去掉，或给对照组补一份英文——否则严格来说这也是一处形式差异。

## 四、曝光测量（`tracker.js`）

**这份文件要原样复制进 `site/`，两组必须用同一套计时口径**，否则曝光时长不可比。

接入：
```html
<body data-arm="control">   <!-- 实验组写 data-arm="narrative" -->
...
<script src="tracker.js"></script>
```

实验组还需要补上与对照组一致的完成码区块：
```html
<section id="gate">
  <h2>阅读完成</h2>
  <p>请在阅读完全文后，点击下方按钮获取完成码，并将其填回问卷。</p>
  <button id="gateBtn" disabled>获取完成码</button>
  <div id="gateCode" aria-live="polite"></div>
  <p id="gateStatus"></p>
</section>
```

记录内容：

- **有效阅读时长** —— 页面不可见时暂停，连续 60 秒无操作时暂停（防挂机）
- **滚动深度** —— 25/50/75/90/100% 里程碑
- **分节停留** —— 每个 `section[id]` 首次进入视口的时刻
- **完成码** —— 达到 `MIN_ACTIVE_SECONDS`（默认 360 秒 = 6 分钟）后才可生成

完成码格式 `TTE-C******-nn`，第 4 位 `C` = 对照组、`N` = 实验组。
**这意味着你可以从答卷上的完成码直接核验被试实际进了哪个网站**——分组失败、串组、跳过材料都能查出来。

参与者编号从链接参数读取：`index.html?pid=答卷编号`。

数据落在 `localStorage`；如需回收到服务器，把 `CONFIG.ENDPOINT` 改成你的接收地址即可（`sendBeacon` + `fetch` 双通道）。调试时在控制台执行 `TTE.json()` 可导出全部数据。

## 五、还需要注意的两个混淆

1. **时间不等长。** 实验组因为有交互、动画、场景切换，wall-clock 时间天然比读一篇文章长。如果实验组共情更高，可能只是因为"接触时间更久"而不是"形式更有效"。
   处理办法：`tracker.js` 已经在记录 `activeSeconds`，**把它作为协变量放进模型**（或做一次以时长匹配的子样本分析）。建议正式投放前先跑 5–10 人小规模预试，看两组实际时长差多少。

2. **新奇效应。** 交互网站本身比文章更"新鲜"，这份新鲜感可能贡献一部分效应。可以在问卷里加一两道题（如"这份材料的形式让我觉得新颖"、"我愿意把它分享给别人"）作为辅助测量，用来在讨论部分区分"共情"与"新奇/趣味"。
